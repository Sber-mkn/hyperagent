# HyperAgent «Кодобольный»

[Тесты моделей](docs/model-tests.html) | [Архитектура системы](docs/ARCHITECTURE.png) | [Презентация](docs/Presentation.pptx) | [Отчет](docs/report.pdf)

Данный проект разделен на две части:
- [Сервер](https://github.com/Sber-mkn/hyperagent)
- [Клиент](https://github.com/Sber-mkn/hyperagent-client)

Сначала необходимо запустить серверную часть. После этого к серверу можно будет подключаться сразу с нескольких клиентов, причем для каждого клиента будет развернут контейнер с его личным агентом. 

## Установка сервера

Клонируйте проект на машину сервера:
```
git clone https://github.com/Sber-mkn/hyperagent.git
```

Создайте .env:
```
cp .env.example .env
copy .env.example .env
```

Запустите проект:
```
docker-compose --profile router up --build
```

После поднятия контейнеров будет запущен модуль Router (маршрутизатор). Он является точкой входа сервера: при запуске клиент отправляет на него логин и пароль пользователя, а маршрутизатор в свою очередь поднимает для данного пользователя личный набор контейнеров (агент, супервизор, личная БД и брокер сообщений). Каждый такой набор контейнеров получает соответствующее имя пользователя в свое название, а также порты для брокера и БД рассчитываются динамически на основе хеша логина и пробрасываются на сервер для того, чтобы все последующие запросы пользователя отправлялись прямо на агента, минуя маршрутизатор. Данный механизм реализован с помощью docker-профилей.

Для удаленной работы сервера необходимо открыть порты.

Linux:
```
sudo ufw allow 5672/tcp
sudo ufw allow 15672:25671/tcp
```

Windows:
```
netsh advfirewall firewall add rule dir=in action=allow protocol=TCP localport=5672
netsh advfirewall firewall add rule dir=in action=allow protocol=TCP localport=15672-25671
```

## Ollama

Для сервера можно запустить Ollama, модели которой по умолчанию будут использоваться агентами. Для этого достаточно запустить ее на одной машине с сервером и удостовериться, что она слушает все интерфейсы.

Если Ollama запущена на другой машине, то необходимо указать ее URL в [.env](https://github.com/Sber-mkn/hyperagent/blob/main/.env.example) (переменная HYPER_OLLAMA_URL). Примечание: изменения в .env файл необходимо вносить до первого подключения клиента, т.к. после поднятия пользовательских контейнеров изменения файла будут проигнорированы.

## Полностью локальный сценарий использования

По умолчанию все модули проекта (сервер, клиенты, Ollama) можно запустить на одной машине, и они будут работать без дополнительных настроек.
